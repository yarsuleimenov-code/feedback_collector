# Working rules

- Prioritize business value, simplicity, usability, maintainability, and delivery speed.
- Keep the Google review and private feedback options equally accessible; do not add review gating.
- Do not send feedback text, rating, email, IP address, or user-agent data to analytics.
- Keep changes scoped to the review collection flow and use minimal diffs.
- Run the production build and browser-check desktop and mobile layouts after UI changes.
